# Changelog

Notable changes to this collection are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Changes awaiting release are grouped under `Unreleased`.

## Unreleased

- Production documentation instructions in `AGENTS.md` for specification selection, authoring contracts, documentation authority, pending-change preparation, and verification.

- Representative `doc-operations/` and `doc-operations-update/` directories, each containing an empty `.gitkeep` file so they are preserved in clones.

### Changed

- Revised `README.md` for human readers, with the collection's purpose, organization, usage, and documentation architecture.
- Moved detailed document-authoring and output conventions from `README.md` into `AGENTS.md`.
